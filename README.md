# Clash Verge Custom Rules (国内防漏直连规则)

这份自定义规则片段专门针对使用 **Clash / Clash Verge Rev** 且开启了 **Fake-IP 模式** 的用户。

## 为什么要用这份规则？

在开启 Fake-IP 模式后，代理软件常常会因为无法及时获取域名的真实 IP 而导致 `GEOIP,CN`（国内 IP 直连）规则失效。这会导致大量国内的图片、视频缓冲、云盘下载等大流量消耗直接掉入代理节点（PROXY），从而**快速消耗机场流量**。

这份规则精选了最容易偷跑代理流量的国内“流量刺客”，强制它们进行直连（DIRECT）。

## 包含的直连场景
- **B 站/哔哩哔哩**：视频流、封面、静态资源缓存。
- **字节/抖音系**：抖音短视频缓存、西瓜视频。
- **腾讯系**：微信/QQ朋友圈图片、腾讯视频。
- **各大网盘**：阿里云盘、夸克网盘、迅雷下载。
- **爱奇艺**：主站及边缘节点 CDN。
- **微博**：微博图片加载。
- **Steam**：Steam 游戏下载 CDN（避免更新大型游戏榨干代理流量）。

## 如何使用？
如果你使用的是 Clash Verge Rev：
1. 打开左侧的 **“配置 (Profiles)”**。
2. 点击右上角的 **“新建 (New)”**，选择类型为 **Rules (规则片段)**。
3. 将 `direct-rules.yaml` 中的内容复制进去并保存。
4. 在你的主配置文件上右键，选择 **“编辑 (Edit)”**，在 `rules` 模块勾选你刚刚新建的规则片段。
5. 右键主配置点击 **“刷新 (Refresh)”** 即可生效。
