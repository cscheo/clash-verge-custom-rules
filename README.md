# Clash Verge Custom Rules (全局架构优化版)

这是一套**全网通用**、**与机场解耦**的 Clash Verge Rev 个人配置库。无论使用什么订阅提供商，套用此配置均可获得一致的防风控、精准分流及去冗余体验。

## 核心架构设计

- **O(1) 极速匹配**：高频使用的国内视频域名被置顶解析，防止每次查询都在庞大的 GEOSITE 库中耗时遍历。
- **免维护动态感知**：废弃了所有硬编码的节点名称。`🤖AI模型专线` 策略组使用正则表达式 `(?i)(美|日|韩|新)` 动态从当前机场抓取可用节点，换机场永不报错。
- **智能防御式脚本**：`remove-fallback.js` 使用正则和底层 `type` 智能识别多余的“自动切换/容灾”组进行全量抹除，并搭载 **Rule Scrubbing（规则清洗）** 引擎，将悬空规则安全重定向至可用组，彻底告别“更新订阅后启动崩溃”。

## 文件配置说明与使用方法

> **强烈建议：** 以下配置不要写在单个订阅里，而是统一配置在 Clash Verge 的 **“设置 -> 全局扩展配置” (Global Profiles)** 中。

1. **`global-merge.yaml`** (底层地基优化)
   - **功能**：强制开启 `store-selected: true` (更新订阅不丢失当前选中的节点) 及关闭系统 hosts 干扰。
   - **用法**：在全局扩展中新建 `Merge`，填入此文件内容。

2. **`direct-rules.yaml`** (路由规则优化)
   - **功能**：优先放行高频国内域名（B站/优酷/爱奇艺等），大库 `GEOSITE,cn` 兜底；阻断机场节点乱切导致的 ChatGPT 验证码/封号问题；将全量 Google AI 域名路由至专属组。
   - **用法**：在全局扩展中新建 `Merge`，填入此文件内容。

3. **`ai-groups.yaml`** (策略组动态抓取)
   - **功能**：自动筛选当前机场的优质国家节点建立 `🤖AI模型专线` 专线。
   - **用法**：在全局扩展中新建 `Merge`，填入此文件内容。

4. **`remove-fallback.js`** (强力杀毒脚本)
   - **功能**：自动嗅探并删除所有的 Auto/自动选择/故障转移 等无用策略组，重构被破坏的路由规则底座。
   - **用法**：在全局扩展中新建 `Script`，填入此文件内容。
